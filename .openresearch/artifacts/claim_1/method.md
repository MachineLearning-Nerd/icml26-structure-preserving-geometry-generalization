# Claim 1 method

`repro/src/run_geo_new.py` evaluates the incidence identities in exact
integer arithmetic where possible and seeded floating-point flux trials where
appropriate. `repro/tests/test_geo_new.py` independently reconstructs the
complete-graph incidence matrix. The negative control changes one incidence
entry and must produce a nonzero residual.

The fixed command is `uv sync --frozen && uv run python repro/src/run_all.py`.
Runtime metadata, raw output, checker output, and the control result are
regenerated by that command.
